# Simulation project

`PMBRA_Maxwell2D.aedt` is the released ANSYS Electronics Desktop/Maxwell 2D
project. It contains the `Maxwell2DDesign1` magnetostatic design, `Setup1`, the
parameter sweeps, and the `Force Table1` report definition used to obtain
`Force1.Force_y`.

The project header identifies ANSYS Electronics Desktop 2025 R1. Open the file
in that release or a compatible newer version. Preserve an untouched copy
before allowing the application to upgrade the project format.

The public copy was scanned as plain-text AEDT content. No workstation absolute
path, username, email address, remote file path, or license-server reference was
found. No separate `.aedtresults` solution/cache directory is distributed;
solve the project locally to regenerate simulation outputs.

`3D_Maxwell_Run_Instructions.md` describes the separate proposed 3D validation
protocol. Project/report screenshots are intentionally excluded from the
code-focused repository.
