# Constant jumping rate

The manuscript comparison uses constant `JR = 0.1`. New runs are configured by the `Constant-q512` entry in `../run_ablation.m`.

The archived `paper_run_level.csv` and `paper_summary.csv` predate both the corrected `JR = 0.1` setting and the strict fixed `MaxFE = 10000` configuration. Their three-variable rows contain 15,000 evaluations, so they must not be treated as regenerated results under the current script.
