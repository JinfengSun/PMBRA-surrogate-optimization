# Simulation project

`Project.aedt` is the ANSYS Electronics Desktop/Maxwell 2D project supplied
with the revised manuscript. It contains the `Maxwell2DDesign1` design,
magnetostatic `Setup1`, `ParametricSetup1`, and the `Force1` force parameter.
The project does not contain solved-result caches; solve it locally and create
or export the required force report from `Force1` as needed.

The revised manuscript records ANSYS Electronics Desktop/Maxwell 2D 2025 R1
(version 2025.2.0), and the project header contains `Version(2025, 2)`. Open the
file in that installation or a compatible newer version. Preserve an untouched
copy before allowing the application to upgrade the project format.
